## Key Findings

### Improvements over previous runs
- 20/30 genuine success on the expanded 30-case set (vs 13/21 = 62% earlier)
- 9/30 honest not_found (anti-hallucination guard working) — these are the
  wins, not failures: agent reports blockage rather than fabricating data
- Avg latency 45 s (down from 52 s on the 21-case set)
- Total cost $0.22 — well under the $0.30 budget

### Anti-hallucination guard validated on real edge cases
- LinkedIn login wall → not_found via blocked_url:/authwall (deterministic URL marker)
- example.com → not_found via hedged-answer phrase ("not_found: ...")
- 404 page → not_found via page_does_not_exist
- Reuters/cnyes/Amazon → not_found via captcha / verification iframe / consent banner
- SEC EDGAR anti-bot → not_found via "Undeclared Automated Tool"

### Real-world finance extraction validated
- cnyes 加權指數: real numeric data extracted (live TAIEX point + change + volume)
- Yahoo TW 2330: real TSMC quote
- MOPS / TWSE: real disclosure pages (with form-fill)
- Yahoo Finance AAPL options: dynamic SPA, ATM call bid/ask

### Honest partial / harder cases
- Form fill (httpbin radio + checkbox + multi-field) is the only hard partial
  remaining — Playwright locator selectors don't always converge on legacy
  `<label>X<input></label>` markup. Documented; future work.
