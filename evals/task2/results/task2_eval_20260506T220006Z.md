## Key Improvements That Drove The Gain

1. v2 prompts with anti-hallucination + early-completion + step-budget rules
2. URL-based blocked-page detection (_BLOCKED_URL_MARKERS) — deterministic catch
   for /authwall, /login, accounts.google.com/signin, /captcha, etc.
3. Healer recovery target extraction — when the LLM suggests an alternative
   role+name pair, the executor actually retries with the different target
4. Expanded popup dismissal — Chinese / Japanese consent buttons + OneTrust /
   TrustArc / Osano selectors
5. Expanded silent-failure phrase list — catches "not_accessible:", "blocked by",
   "behind a paywall", "captcha challenge", Chinese variants
